Para especialistas

El orden sale de preanalitica_orden.tsv. El número de precursores se une solo cuando el identificador coincide con suero_calidad_muestra.tsv. Las filas HC_ no se igualan a las filas Normal_.

Lo que aprendiste

  • Coagulación, eritrocitos y plaquetas cambian el suero.
  • Un lote alineado con el grupo no se puede separar del grupo.
  • Aquí el orden y el grupo van juntos.
