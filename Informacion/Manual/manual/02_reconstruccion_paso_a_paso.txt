crc_proteomics_go_ai

2. Crear subcarpetas

metadata/protein_id_maps/
metadata/clinical_labels/
metadata/gene_ontology/

src/utils/
docs/

reports/

- README.md

- environment.yml
- mkdocs.yml
- config/config.yaml

- metadata/sample_metadata/*.tsv

4. Crear ambiente
Ejecutar en la raíz del proyecto:
conda env create -f environment.yml
conda activate crc-proteomics-go-ai

5. Validar entorno
python --version
pip show pandas
pip show scikit-learn
pip show gseapy
pip show networkx

6. Completar metadatos
Crear o completar:
- cptac_metadata.tsv
- plasma_metadata.tsv
- pride_merged_metadata.tsv
- crcdb_metadata.tsv
- pharmacoproteomics_metadata.tsv
- protein_mapping_master.tsv

7. Descargar datasets y renombrar
- CPTAC -> data/raw/cptac/protein_abundance.tsv
- PRIDE -> data/raw/pride/pride_merged.tsv
- plasma -> data/raw/plasma/plasma_abundance.tsv
- crcdb -> data/raw/crcdb/crcdb_context_matrix.tsv (si se usa)
- farmacoproteomics -> data/raw/pharmacoproteomics/pharmacoproteomics_abundance.tsv

8. Verificar consistencia
Asegurar que los nombres de columnas de muestra coincidan exactamente con los valores sample_id de cada metadata.
